# Contributing

Read [AGENTS.md](AGENTS.md) for the repo's operating, git, PR, privacy, and iteration rules. It is the single source of truth so humans and agents follow the same process.

Check [STATE.md](STATE.md) before relying on a mode. Use the [lesson template](lessons/README.md) to record general evidence and the [proposal template](proposals/README.md) for front switches or role reassignments. Behavior changes require a PR and human approval because they affect every user.
